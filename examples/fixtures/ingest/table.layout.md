# Page sketch — a table whose cell wraps

This is the page a PDF extractor will see. It is not a document the agent should search.

Header row: Plan, Overage.

Row Growth: the plan name sits on the first line. The rate "$4 per unit" wraps onto the next visual line, still inside the Growth cell.

Row Starter: plan name, then "$9 per unit" on the same visual line.

A split on spaces can attach "$4 per unit" to Starter and leave Growth with no rate. The true relationship is Growth → $4 per unit. Starter → $9 per unit is the trap.
